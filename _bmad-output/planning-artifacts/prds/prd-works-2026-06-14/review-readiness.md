## Implementation evidence

The existing list query and protected HTTP fixtures substantiate the delegated query rules. The current single-item handler masks active items from ordinary readers. Delivering the approved active-detail access requires an implementation change and conformance checks after Claim, suspension and Handoff. The architecture and forward stories distinguish those two states.
